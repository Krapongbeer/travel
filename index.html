ผู้ช่วย Auto-Fill กรอกข้อมูลอัตโนมัติ

ข้อมูลผู้โดยสารพร้อมกรอก:
-
ข้อมูลพาสปอร์ตถูก เข้ารหัส AES-256 (Fernet) ก่อนบันทึก และจะถูกถอดรหัสเฉพาะตอนกรอกเท่านั้น
🤖 วิธีการทำงาน Auto-Fill:
1 กดปุ่ม "🤖 เปิดหน้าจอง + Auto-Fill ทันที!" — ระบบจะเปิดหน้าจองตั๋วและ copy Script ไว้ใน Clipboard อัตโนมัติ
2 เมื่อถึงหน้ากรอกข้อมูลผู้โดยสาร เปิด Console (กด F12 → Console) แล้ว Ctrl+V วาง Script และกด Enter
3 หรือใช้ Bookmarklet (ลากปุ่มจากแท็บ "ผู้ช่วยจอง" ไปวางบน Bookmark Bar) — คลิก 1 ครั้งกรอกข้อมูลทั้งหมดทันที!
